## 핵심 쟁점 · 2026.10.27

1. **중요 정정:** 광명3M 지구단위계획구역은 철산동 484-5번지 일대로, 광명동 159번지 상가와 같은 구역이라고 전제하면 안 됩니다.
2. LH는 2026.05.08 최초 신청, 07.30 보완 신청. 두 신청안 도면의 상가 편입·제척 여부는 아직 비교할 원본 자료가 없습니다.
3. 2025.10.20 시의회 회의록의 ‘159번지 일대 제척’ 발언은 당시 근거 도면과 법적 단계 확인이 필요합니다.
4. 상가 포함안과 제척안의 도로·교통·소방·기반시설 비교 검토자료 확보가 핵심입니다.
5. 10월 19일 공람은 촉진계획 변경안이며, 이것만으로 상가 최종 편입·제척이 확정된 것은 아닙니다.
