## 새 상황 발생 시 정리 규칙

1. 발생일과 정리일을 구분하고, 새 날짜의 `archive/YYYY-MM-DD.html` 상세 기록을 작성합니다.
2. 해당 시점의 **포인트별 카드**를 추가하고 관련 공식 근거·문서·이미지 원본을 연결합니다.
3. 루트 `index.html`에 **최신 정리 시점**을 앞쪽에 추가합니다.
4. `updates/`에서 새 사실·기존 내용과의 차이·정정사항을 남깁니다.
5. 문서 원본의 개인정보·공개 적정성을 검토한 뒤 링크 상태와 `data-status.html`을 점검합니다.

**중요:** 광명3M은 철산동 484-5 일대이며 광명동 159번지 오리로 대로변 상가의 법적 구역명으로 단정하면 안 됩니다. 해당 상가의 최종 편입·제척 상태는 결정도면 확인이 필요합니다.

자동 수집·게시 기능은 현재 설치되지 않았으며 새로운 상황을 확인할 때 갱신하는 구조입니다.
